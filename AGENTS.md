# Работа с учебными материалами

- Пишите материалы на русском языке, с учётом 6 класса российской школы.
- Соблюдайте согласованные правила в `study-rules.md`, особенно правило выбора задания по английскому от репетитора или по той же теме при отсутствии домашнего задания.
- Не выдумывайте номера упражнений, содержание тетрадей, расписание репетитора и его домашние задания.
- Отделяйте выполненные задания от запланированных; не отмечайте выполнение без подтверждения.
- Не делайте выводов о способностях или профессии по оценкам и короткому опросу интересов.
- Используйте существующий checkout: облачная задача уже изолирована. Не создавайте Git worktree без прямой просьбы пользователя.
